# Методы API

Для POST передавайте JSON с заголовком `Content-Type: application/json`. Методы работы с заметками принимают заголовок `Authorization: Bearer <access_token>`.

| Метод | Данные запроса | Успешный ответ |
| --- | --- | --- |
| `POST /auth/login` | Строки `username` и `password` | `200`, `access_token`, тип `Bearer` и срок 900 секунд |
| `GET /api/data` | JWT | `200`, список `items` с `id` и `body_html` своих заметок |
| `POST /api/data` | JWT и строка `body` до 1000 символов | `201`, идентификатор `id` и экранированный текст `body_html` |

## Реализация защиты

- Пароли хэшируются с помощью Argon2id. Библиотека создаёт случайную соль и кодирует её вместе с параметрами и хэшем. Для неверного пароля и неизвестного пользователя API возвращает одинаковый ответ `401`.
- При успешном входе сервис выдаёт JWT на 15 минут. Общий декоратор проверяет подпись HS256, обязательные claims, срок действия и наличие пользователя. Идентификатор владельца заметки берётся из проверенного токена.
- SQLite получает параметры отдельными значениями. SQL остаётся фиксированным при поиске пользователя, записи и чтении заметок. Клиент может передать только текст заметки.
- SQLite хранит исходный текст. Перед отправкой API один раз экранирует пользовательский текст через MarkupSafe и возвращает его в поле `body_html` для текстового контекста HTML. Ответ имеет тип `application/json` и заголовок `X-Content-Type-Options: nosniff`.
